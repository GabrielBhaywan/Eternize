# Eternize Planos

Landing page estática para a Eternize Planos, feita sem bibliotecas de interface.

## Abrir

Abra `index.html` em um navegador. Para testar vídeo local corretamente, use um servidor estático simples e coloque o arquivo de vídeo no caminho indicado abaixo.

## Materiais para substituir

- Carrossel de Beneficios: adicione imagens reais em `assets/images/beneficio-<categoria>.jpg` para as 14 categorias listadas em `index.html`. Os placeholders aparecem ate os arquivos existirem.

- `index.html`: comentário `LOGO AQUI` para a marca oficial.
- `assets/videos/hero-velas.mp4`: vídeo curto, sem áudio e otimizado para a Hero.
- `assets/images/hero-fallback.jpg`: preparar uma imagem real e ajustar o bloco `hero-fallback` em `index.html` para usar `<img>`; o placeholder atual continua visível se vídeo/autoplay falharem.
- Comentários `IMAGEM INSTITUCIONAL`, `FOTO DA CONSULTORA` e `IMAGEM CARTÃO DU` em `index.html` identificam os espaços de imagens reais.
- Google Maps: o iframe do footer usa uma localização provisória na Avenida Paulista, São Paulo. Substitua o endereço da busca e o texto de localização pelo endereço real confirmado.
- `REDES SOCIAIS AQUI`, `[ INSTAGRAM AQUI ]` e `[ FACEBOOK AQUI ]`: adicionar os perfis oficiais.
- `[ CNPJ AQUI ]`: inserir os dados legais oficiais.

Os materiais na pasta `ref/` serviram como referência de identidade visual. Textos e condições comerciais da landing page foram limitados ao briefing; informações adicionais presentes nas artes não foram presumidas como condições oficiais.

## Conteúdo comercial

Os dados dos planos, os valores de adesão e o acréscimo acima de 65 anos ficam em `index.html`. Revise o telefone nos links `wa.me` e no conteúdo visível se o contato mudar.
